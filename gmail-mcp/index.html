Personal Gmail MCP

A single-user tool for managing one personal mailbox.

Personal Gmail MCP is a locally run Model Context Protocol server that lets its operator read and organize their own Gmail from a command-line assistant. It runs on one machine, for one person, and is not offered as a product or service to anyone else.

What it does

  • Reads messages, threads, and labels from the operator's own mailbox
  • Organizes mail: applying labels, archiving, marking read or unread, moving to Trash
  • Composes, drafts, and sends mail as the operator
  • Reads and updates basic settings such as filters and signatures

What it does not do

  • It does not permanently delete mail. Deletion goes to Trash and follows Gmail's normal retention.
  • It does not access any mailbox other than the one that authorized it.
  • It has no server, no accounts, and no other users.
