Privacy policy

Personal Gmail MCP · last updated August 21, 2026

Personal Gmail MCP is a single-user tool. It is installed and run by one person on their own computer, and it accesses only the Gmail account that authorized it. There are no other users, no accounts, and no hosted service.

What data is accessed

When the operator runs the tool, it uses the Gmail API to read and modify mail in their own mailbox: message content, headers, attachments, labels, threads, and basic settings such as filters and signatures. Access is limited to the gmail.modify and gmail.settings.basic scopes.

Where data goes

Mail content is exchanged directly between the operator's computer and Google's Gmail API. It is not sent to any server operated by this application, because no such server exists. Data appears only in the operator's local command-line session and in whatever files the operator chooses to save.

Storage and retention

The only data written to disk by the tool is OAuth credential files stored locally at ~/.gmail-mcp/, readable only by the operator's user account. No copy of the mailbox is retained. Revoking the application's access at myaccount.google.com/permissions and deleting that directory removes all stored data.

Sharing

No data is sold, shared, transferred, or disclosed to any third party. There is no analytics, telemetry, or advertising of any kind.

Google API Services User Data Policy

This application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
